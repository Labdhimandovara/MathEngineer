# MathEngineer — Product Vision

## Product

MathEngineer is an interactive mathematics learning platform designed specifically
for undergraduate engineering students.

The goal is not simply to provide answers.

MathEngineer should help students:
- understand mathematical concepts
- solve problems independently
- receive progressive hints instead of immediately seeing answers
- understand exactly where they made a mistake
- practice weak topics
- prepare for university examinations
- build confidence through small, measurable successes

## Initial Scope

The first version focuses exclusively on:

Numerical Techniques

Initial topics:
1. Bisection Method
2. False Position Method
3. Newton-Raphson Method

The product will later expand to:
- iterative methods for linear systems
- Gauss-Jacobi
- Gauss-Seidel
- matrix norms
- condition number
- additional numerical methods
- probability and statistics
- other engineering mathematics subjects

## Core Learning Philosophy

MathEngineer follows:

Learn → Attempt → Hint → Attempt Again → Diagnose Mistake → Understand → Practice

The system should encourage students to solve problems themselves.

When a student starts a question, the application should prefer asking:

"Do you want to solve this yourself, use hints, or see the solution?"

The default experience should encourage independent solving.

## Important Product Principles

1. Do not immediately reveal answers.
2. Hints should progressively increase in specificity.
3. Detect and explain mistakes, not just mark answers wrong.
4. Mathematical calculations should eventually be verified using deterministic
   mathematical logic rather than relying entirely on an LLM.
5. Explanations should be understandable to undergraduate engineering students.
6. Students should be able to ask follow-up questions naturally.
7. The platform should eventually support English, Hindi and Hinglish.
8. The platform should eventually support voice interaction.
9. Gamification should encourage learning rather than mindless app usage.
10. The application should feel like a thoughtful educational product,
    not an AI chatbot.

## Initial User

The primary user is an undergraduate engineering student who needs help
understanding and practicing mathematics-heavy subjects.

The initial experience should be optimized for a student studying Numerical
Techniques for university examinations.

## Product Personality

MathEngineer should feel:

- intelligent
- calm
- approachable
- modern
- youthful
- academically credible
- motivating
- human

It should NOT feel:

- corporate
- childish
- overly futuristic
- robotic
- like a generic AI wrapper
- like a generic SaaS dashboard
