# MathEngineer — Design System

## Visual Direction

The visual identity is inspired by soft lavender, warm cream, editorial
layouts and natural photography.

The product should feel like a beautifully designed Gen-Z study environment,
not a conventional educational dashboard.

Reference aesthetic:
- soft lavender
- warm cream
- dusty purple
- warm neutral backgrounds
- dark charcoal typography
- natural photography
- editorial spacing
- subtle rounded corners
- restrained animations

The attached visual references should be treated as aesthetic inspiration,
not as templates to copy.

## Color Distribution

Use approximately:

70% — very light lavender / warm white / cream backgrounds
20% — neutral surfaces and secondary background tones
10% — dark typography, lavender accents and functional emphasis

Do NOT make the entire interface purple.

Purple should be an accent and atmosphere, not the dominant UI color.

## Typography

Use a refined modern sans-serif for the main interface.

Typography should have:
- clear hierarchy
- generous line height
- comfortable reading width
- large section headings
- restrained use of bold

Avoid excessive all-caps text.

Optional editorial serif typography may be used sparingly for
small decorative headings or quotes, but the main educational interface
must remain highly readable.

## Layout

Use generous whitespace.

Avoid dense dashboard layouts.

Cards should not be everywhere.

Use cards only when they improve hierarchy.

Prefer:
- open layouts
- clear sections
- subtle borders
- soft surfaces
- breathing room

## Border Radius

Use moderately rounded corners.

Avoid extremely rounded "pill everything" UI.

Buttons can have rounded corners but should still feel sophisticated.

## Shadows

Use extremely subtle shadows.

Avoid heavy floating-card shadows.

## Icons

Use a restrained icon system.

DO NOT use:
- robot icons
- generic AI sparkle icons
- excessive stars
- glowing AI effects
- random magic-wand icons
- futuristic circuit patterns
- AI brain illustrations
- decorative neural-network patterns

The product should feel human-designed.

## Photography

Use natural, editorial photography when imagery is appropriate.

Preferred imagery:
- students studying
- notebooks
- desks
- natural light
- books
- university environments
- subtle lifestyle photography

Photography should feel candid and natural.

Avoid:
- obvious corporate stock photos
- people pointing at laptops
- exaggerated "AI" imagery
- robots
- neon technology imagery

Do not add random stock images just to fill empty space.

If appropriate imagery is not available, use whitespace instead.

## Animation

The website should feel alive but calm.

Use:
- subtle page transitions
- gentle fade/slide reveals
- small hover movements
- progress animations
- smooth navigation
- subtle number/count animations

Avoid:
- excessive bouncing
- constant movement
- flashy particle effects
- background animations
- unnecessary loading animations

## Modes

### Calm learning experience

Learn/Solve/Practice should feel:
- calm
- focused
- spacious
- soft
- low visual noise

### Challenge experience

Challenge/Battle mode should feel:
- energetic
- faster
- focused
- competitive
- visually distinct

However, it should still belong to the same visual identity.

Do not suddenly turn Challenge Mode into an esports/gaming website.

## Mobile

Mobile responsiveness is essential.

The experience should work beautifully on:
- phone
- tablet
- laptop
- desktop

The question-solving interface must be especially good on mobile.

## General Rule

Every design decision should answer:

"Would a thoughtful human designer actually make this choice?"

Avoid adding UI elements simply because they are common in AI-generated websites.
